# 📝 java-calculator-precourse 기능 목록

### ▪️ 입력 기능

- [] 구분자와 양수로 구성된 문자열 입력
    - [] 입력값이 비었다면 `0` 반환

### ▪️ 비지니스 기능

- 문자열로부터 커스텀 구분자 추출하기
    - [] 문자열 앞부분의 `//`와 `\n` 사이의 문자를 커스텀 구분자로 지정
    - [] 예외🚨: 구분자가 `숫자`면 예외 메세지 반환 후 종료
    - [] 예외🚨: 구분자가 `빈 문자열`이면 예외 메세지 반환 후 종료

- 문자열로부터 숫자 추출하기
    - [] 구분자를 기준으로 숫자 추출하기
    - [] 예외🚨: 음수, 0, 실수가 포함되어 있으면 예외 메세지 반환 후 종료
    - [] 예외🚨: `,`, `:`, `커스텀 구분자` 외 구분자가 포함되어 있으면 예외 메세지 반환 후 종료
    - [] 예외🚨: 숫자가 존재하지 않으면 예외 메세지 반환 후 종료

- 계산하기
    - [] 모든 숫자 덧셈 하기
    - [] 예외🚨: 합이 범위를 넘는 경우 예외 메세지 반환 후 종료

### ▪️ 출력 기능

- [] 덧셈 결과 출력
    - [] 구분자를 기준으로 분리한 각 숫자의 합 반환
